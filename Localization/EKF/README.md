# LocEKF

`ChassisLocalization::EKF` 提供平面融合定位后端 `LocEKF<StateBufferCapacity, InputBufferCapacity>`，继承 `IChassisLoc`，融合 Motion 反馈、`HWT101CT` 航向和外部位姿观测。依赖见 [cpkg.toml](cpkg.toml)：`Chassis::Core`、`Math::EKF`、`SensorGyro::HWT101CT`、`libs::Concurrency`、`libs::Deque`。当前实现使用 `HAL_GetTick()`，这是真实的 HAL 时间基准依赖，而不是可任意替换的抽象时钟接口。

本包不创建传感器、通信或周期任务。共同分层和控制权见[仓库综述](../../README.md)；逐符号及滤波实现细节见 [LocEKF.hpp](LocEKF.hpp) 的现有 Doxygen。

## 输入、坐标与输出

- Motion 提供车体系速度；`HWT101CT` 提供 yaw / wz；`updateLidar(pos, ticks)` 接收外部世界系位姿，来源不限定于某种雷达或 SLAM。
- 输入和输出位置使用 `m`、线速度使用 `m/s`、yaw 使用 `deg`、角速度使用 `deg/s`。外部观测不可直接混入 `rad`，世界系原点和朝向必须与初始状态一致。
- `postureInWorld()` 输出融合位姿，其 yaw 包含估计的航向偏移；初值的 yaw 与 yaw_offset 共同决定对外朝向。
- `velocityInBody()` 的平移速度来自 Motion，角速度在启用陀螺仪时来自陀螺仪，否则来自 Motion；`velocityInWorld()` 使用当前融合朝向旋转该速度。
- 输出 yaw 使用连续角语义，不强制截断到 `[-180, 180]`；外部观测的 yaw 残差按最近等效角融合，不能用该后端保证累计旋转圈数。

## 构造与初始状态

先建立 Motion 和陀螺仪，并保证它们比 Loc 存活更久。`Config` 提供初始状态、初始协方差、过程噪声和陀螺仪 / 外部位姿观测噪声；参数应依据实际输入精度配置，而不是复用某个固定机器人的调参值。

若初值由外部定位首帧与陀螺仪首帧共同确定，应先运行 Motion 与设备，等待这些输入可用，再准备初值并构造 Loc，最后构造 Controller。不能在尚未建立可靠世界系时就进入依赖定位的控制模式。需要重新初始化时，`resetState(cfg)` 会重置状态和协方差并丢弃旧历史，不保留原有回放窗口。

## 时间基准与周期入口

1. 固定周期调用 `update()`，采样 Motion、陀螺仪和本地 HAL tick，并推进滤波。
2. 构造参数 `delta_ticks` 表示相邻周期预计相隔的 HAL tick 数；当前实现直接按 `delta_ticks * 0.001f` 换算秒，要求 HAL tick 为 `1ms`，不是自动探测频率或按两次真实采样间隔计算 dt。调用节拍必须与该值对齐。
3. 外部定位到达时调用 `updateLidar(pos, ticks)`；`ticks` 应是该观测对应的采样时刻，且必须与 `update()` 内部采样的本地 HAL tick 使用同一时基，不能简单以接收时刻替代。
4. 若观测来自其他时钟，调用方先完成时间映射或对时，再传入已换算的时间戳。本包不负责跨 MCU、板卡或通信链路的自动对时。

宿主负责周期、观测回调的调度与生命周期；现有回放实现有周期推进不被其回放入口打断等并发前提，不能把内部同步手段理解成任意线程 / 中断组合均安全。应结合头文件说明安排调用上下文，不在本文复制锁算法。

## 晚到观测、容量与 RAM

不早于最新状态的观测直接融合；晚到但仍在历史范围内的观测会回溯融合并重放后续输入。早于可回溯窗口的观测会被丢弃，因此时间基准错误或容量不足都可能使期望的延迟补偿失效。

`StateBufferCapacity` 指定历史状态点数，必须大于零；`InputBufferCapacity` 指定待推进的输入点数，默认 `4`，也必须大于零。历史窗口取决于状态点数及更新周期，输入容量则需覆盖回放期间待处理输入。两者均由调用方根据延迟、回放耗时和 RAM 预算选择，不能把某个固定容量当作全项目默认值。例如 `chassis::loc::LocEKF<128>` 表示选择 128 个历史点，而不是 128 ms 的独立保证。

## 适用边界

这是二维平面位姿融合，仅使用 yaw / wz，不提供完整三维姿态或六轴 / 九轴 IMU 状态估计。包不修复宿主时基、采样周期和传感器坐标错误，也不负责上层控制模式的安全切换。具体配置字段、观测开关和重置行为以 [LocEKF.hpp](LocEKF.hpp) 的现有 Doxygen 为准。
